# Wiki source

This folder contains the **wiki** for the Android Management API Home Assistant integration.

## Using this wiki

- **On GitHub**: You can use these Markdown files as the source for the repository’s [GitHub Wiki](https://github.com/Shaffer-Softworks/Android-Management/wiki). Clone the wiki repo, copy these files in (using `Home.md` as the main page), and push. The existing README links to `#initial-setup`, `#post-setup-advice`, and `#debug-logging` on the main wiki page; [Home.md](Home.md) includes those sections and anchors.
- **In-repo**: You can also treat this folder as the canonical documentation and link to it from the main README (e.g. `wiki/Initial-Setup.md`).
